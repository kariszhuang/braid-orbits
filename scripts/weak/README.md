# Weak pair-generation failures

The long discovery campaign for weak failures (`run_campaign.py`: start, stop, resume, status), the defect questions, and checks of the certified A25 and S18 examples.

| file | what it does |
|---|---|
| `analyze_escape_words.py` | Literal positive-word audit of closed exported proof tables; stdlib only. |
| `analyze_fixed_braid_constraints.py` | Literal audit of fixed-braid constraints in existing weak certificates. |
| `analyze_defect_mission.py` | Dependency-free descriptive reconciliation; no pretend independent walk samples. |
| `analyze_weak_mechanisms.py` | Exact braid-image/passport-fiber and characteristic-polynomial checks. |
| `benchmark_campaign_cache.py` | Paired old/full-scan versus RAM-cached progress export; synthetic exact files. |
| `benchmark_discovery.py` | Finite paired discovery benchmarks. |
| `benchmark_structured.py` | Sequential before/after complete-passport measurements, including class setup. |
| `check_small_passport_mission.py` | Sequential finite checks for the small-passport mission, with frozen evidence. |
| `check_useful_repair.py` | Locked, sequential bounded checks/paired comparisons; no competing hunt. |
| `check_weak_extensions.py` | Bounded sequential technical validation beside the unchanged main campaign. |
| `check_weak_roadmap.py` | Finite, locked validation of the seven-direction weak-search roadmap. |
| `compact_campaign_metadata.py` | Preserve then pack AppleDouble metadata of finished historical weak jobs. |
| `odd_order_spin.py` | Bounded exact odd-order lift invariant in the Clifford model of 2.A_n. |
| `remaining_weak_passports.py` | Exact coverage map for specified XXYY/XXXY passport profiles, not all tuples. |
| `run_campaign.py` | Build, verify, and run resumable research campaigns. |
| `run_joint_stability_checks.py` | Bounded policy-eleven validation; writes new evidence, never launches a hunt. |
| `run_defect_mission.py` | Plan first; run only with --run. |
| `run_s18_linked_roots.py` | Finite linked-root census; shares the discovery lock, preserves raw evidence. |
| `verify_braid_symmetry.py` | Independent SymPy group-order check of Rust's one-state braid certificate. |
| `verify_exact_a9_slices.py` | Run bounded, exact fixed-first-entry A9 slices and independently check their mass. |
| `verify_weak_graph_extensions.py` | Replay saved structural claims from raw permutations, not analysis helpers. |
| `weak_graph_extensions.py` | Exact saved-graph investigations; no discovery search or floating gaps. |

Tests (5): `test_campaign_cache.py`, `test_campaign_runner.py`, `test_compact_campaign_metadata.py`, `test_defect_mission.py`, `test_s18_linked_roots.py`
